## About Seurat

[Seurat documentation](https://satijalab.org/seurat/)

**Seurat** is an R package designed for the quality control, analysis, and exploration of single-cell RNA-seq data. It provides a range of tools for processing single-cell datasets and identifying biological patterns and sources of variation between cells.

In this tutorial, Seurat will be used to take the gene expression matrix generated by Cell Ranger and perform downstream analysis, including **quality control, normalization, dimensionality reduction, clustering, visualization, identification of marker genes, label transfer and differential gene expression analysis**.

Before starting the analysis, we need to install and load the required R packages. Loading these packages gives us access to the functions and tools used throughout the workflow and ensures that all required dependencies are available.

### Installing the required packages

The following code checks whether each package is already installed. If a package is missing, it will be installed automatically. This allows the script to be run again without unnecessarily reinstalling packages.

```r
# =============================================================================
# INSTALL REQUIRED R PACKAGES
# =============================================================================

# This section installs all packages required for the single-cell RNA-seq
# analysis. Packages are only installed if they are not already available.

# -----------------------------------------------------------------------------
# 1. CRAN packages
# -----------------------------------------------------------------------------

cran_pkgs <- c(
  "Seurat",
  "SeuratObject",
  "ggplot2",
  "dplyr",
  "patchwork",
  "future",
  "hdf5r",
  "BiocManager"
)

# Identify missing CRAN packages
new_cran <- cran_pkgs[
  !vapply(cran_pkgs, requireNamespace, logical(1), quietly = TRUE)
]

# Install missing packages
if (length(new_cran) > 0) {
  install.packages(new_cran)
}


# -----------------------------------------------------------------------------
# 2. Bioconductor packages
# -----------------------------------------------------------------------------

# glmGamPoi is used by Seurat's SCTransform workflow
bioc_pkgs <- c("glmGamPoi")

# Identify missing Bioconductor packages
new_bioc <- bioc_pkgs[
  !vapply(bioc_pkgs, requireNamespace, logical(1), quietly = TRUE)
]

# Install missing Bioconductor packages
if (length(new_bioc) > 0) {
  BiocManager::install(new_bioc, ask = FALSE, update = FALSE)
}


# -----------------------------------------------------------------------------
# 3. Verify installation
# -----------------------------------------------------------------------------

message("All required packages are installed.")

```

Here, most of the packages are installed from **CRAN**, while `glmGamPoi` is installed through **Bioconductor**. `glmGamPoi` is used by the SCTransform v2 workflow for normalization.

### Loading the libraries

Once the packages are installed, they need to be loaded into the R session:

```r
# =============================================================================
# 2. LOAD LIBRARIES
# =============================================================================

library(Seurat)
library(SeuratObject)
library(ggplot2)
library(dplyr)
library(patchwork)
library(future)
library(hdf5r)
```

Each package provides functionality that will be used during the analysis. For example, **Seurat** provides the main single-cell analysis functions, **ggplot2** is used for visualization, **dplyr** provides tools for manipulating data, and **patchwork** allows multiple plots to be combined into a single figure.

### Setting a seed

Finally, we set a random seed:

```r
# Reproducibility
set.seed(42)
```

Setting a seed helps make analyses involving random processes reproducible. For example, some steps may involve random sampling or initialization. Using the same seed means that, where possible, the same analysis will produce the same result when the code is run again.

With the required packages installed and loaded, we can now begin working with the **Cell Ranger output and create our Seurat object**.
