# Clustering and Annotation

In this section, we will identify groups of cells with similar gene expression profiles
and determine their biological identities using marker genes and reference-based annotation.

## Workshop files

-   `clustering_annotation_BA.R` -- R script for hands-on session
-   `clustering_annotation_BA.Rmd` -- Markdown script for hands-on
-   `clustering_annotation.html` -- Completed tutorial with expected
    outputs
-   `seurat_preprocessed_SCT.rds` -- pre-processed Seurat object
    used for the practical

## Instructions

1.  Download this folder.
2.  Open `clustering_annotation_BA.R` or `clustering_annotation_BA.Rmd` in RStudio.
3.  Set the path to the workshop data on your computer.
4.  Install the required packages using the installation section of the
    script.
5.  Run the script sequentially from top to bottom.

If you are unable to run the analysis, open `clustering_annotation.html`
to follow the practical and view the expected results.
